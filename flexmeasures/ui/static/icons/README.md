# Asset type icons

These SVG icons come from [Iconify](https://iconify.design/), which serves them from the icon sets below.
`SVG_ICON_MAPPING` in `flexmeasures/ui/utils/view_utils.py` refers to them by path.
They are committed, rather than fetched like the UI's libraries, because Iconify renders them on request, so they have no fixed release to fetch from.

| Directory | Icon set | Author | Licence |
|---|---|---|---|
| `mdi/` | [Material Design Icons](https://github.com/Templarian/MaterialDesign) | Pictogrammers | Apache 2.0, see `licenses/Apache-2.0.txt` |
| `material-symbols/` | [Material Symbols](https://github.com/google/material-design-icons) | Google | Apache 2.0, see `licenses/Apache-2.0.txt` |
| `fa-solid/` | [Font Awesome 5 Solid](https://github.com/FortAwesome/Font-Awesome) | Dave Gandy | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `wi/` | [Weather Icons](https://github.com/erikflowers/weather-icons) | Erik Flowers | SIL OFL 1.1, see `licenses/OFL-1.1.txt` |

`material-symbols/add-rounded-white.svg` is `material-symbols/add-rounded.svg` as Iconify renders it with `?color=white`.
